# 🏦 Bank Loan Applications Dashboard

##  Project Overview

The **Bank Loan Applications Dashboard** is an interactive Excel dashboard designed to analyze loan application data and provide meaningful insights into loan performance, funding, repayments, customer borrowing behavior, and risk indicators.

This project demonstrates the use of **Microsoft Excel, PivotTables, PivotCharts, slicers, formulas, data visualization, and dashboard design** to transform raw loan data into an interactive business intelligence solution.

The dashboard allows users to quickly monitor important KPIs, identify trends, compare good and bad loans, and understand loan applications across different states, purposes, terms, and employment lengths.


##  Project Objectives

The main objectives of this project are to:

* Analyze overall loan application performance
* Track funded and received loan amounts
* Compare good loans vs. bad loans
* Monitor monthly loan application trends
* Analyze loan applications by purpose
* Understand loan distribution across U.S. states
* Analyze applications by loan term
* Evaluate applications based on employment length
* Monitor average interest rate
* Monitor average debt-to-income ratio
* Create an interactive and easy-to-understand financial dashboard

##  Dashboard Analysis

### 1. Good Loan vs. Bad Loan Analysis

The dashboard separates loans into **Good Loan** and **Bad Loan** categories.

This analysis helps understand:

* Number of applications
* Funded amount
* Amount received
* Percentage distribution
* Overall loan quality

The dashboard shows that **Good Loans represent the majority of applications**, while Bad Loans represent a smaller portion of the portfolio.



### 2. Loan Applications by Month

The monthly trend chart shows how loan applications change throughout the year.

This helps identify:

* Monthly growth
* Seasonal patterns
* High and low application periods
* Overall application trends

The dashboard shows an **upward trend in loan applications toward the end of the year**.



### 3. Loan Applications by Term

Loan applications are analyzed based on different loan terms, including:

* 36 Months
* 60 Months

This analysis helps understand customer preferences regarding short-term and long-term borrowing.



### 4. Loan Applications by Employment Length

The dashboard analyzes loan applications according to employment duration.

Categories include:

* `< 1 year`
* `1 year`
* `2 years`
* `3 years`
* `4 years`
* `5 years`
* `6 years`
* `7 years`
* `8 years`
* `9 years`
* `10+ years`

This provides insight into the relationship between employment stability and loan applications.


### 5. Loan Applications by State

The geographical map visualizes loan applications across different U.S. states.

It helps identify:

* States with high application volumes
* Regional loan demand
* Geographic concentration
* Differences in borrowing activity



### 6. Loan Applications by Purpose

The dashboard analyzes the reasons customers apply for loans.

Major purposes include:

* Debt Consolidation
* Credit Card
* Other
* Home Improvement
* Major Purchase
* Car
* Wedding
* Medical
* Moving
* House
* Educational
* Renewable Energy

This helps identify the most common customer borrowing needs.



### 7. Interest Rate Analysis

The dashboard compares average interest rates across different loan statuses:

* Charged Off
* Current
* Fully Paid

This provides a useful view of how interest rates vary across loan performance categories.



##  Interactive Filters

The dashboard includes interactive filters that allow users to analyze loan applications based on different dimensions.

Users can filter the dashboard by:

* **Grade**
* **Loan Purpose**

These filters dynamically update the dashboard visuals and KPIs, making it easier to perform focused analysis.

#  Key Business Insights

The dashboard provides several useful business insights:

1. **Loan applications reached approximately 14.4K**, indicating significant customer demand.

2. **$169.0M was funded**, providing an overview of the total lending activity.

3. **$183.5M was received**, allowing comparison between funded and received amounts.

4. **Good loans account for the majority of applications**, while bad loans represent a smaller share.

5. **Debt consolidation is the leading loan purpose**, indicating that managing existing debt is a major borrowing requirement.

6. Loan applications show a **strong upward trend during the year**, with the highest application volume occurring toward December.

7. **36-month loans represent a larger share than 60-month loans**, showing a preference toward shorter loan terms.

8. Employment length analysis provides insight into the borrowing behavior of customers with different employment histories.
